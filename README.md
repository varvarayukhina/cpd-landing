# Лендинг Центра пренатальной диагностики Е.Н. Андреевой

Две версии одной страницы, между которыми переключает тумблер **Коротко ⇄ Подробно** в шапке.

| Файл | Что это |
|---|---|
| `index.html` | Короткая версия. Минимум текста, весь упор на запись. УТП — приём 7 дней в неделю |
| `full.html` | Полная версия: карта беременности по неделям, калькуляторы, FAQ, блоки для врачей |
| `mark.png` | Знак логотипа с прозрачным фоном (шапка, favicon) |
| `logo.png` | Полный круглый логотип с текстом |
| `NAMES.md` | Варианты названия вместо OSCAR |

## Что нужно заменить перед публикацией

- Телефоны `8 800 000-00-00` и `8 800 000-00-01`
- Почта `info@example.ru`
- Адрес — сейчас «г. Москва, ул. Примерная, д. 1 (уточняется)»
- Фотография Е.Н. Андреевой — на её месте плейсхолдер, портрет 4:5, примерно 800×1000
- Данные о Е.Н. Андреевой взяты из открытых источников и требуют финальной сверки

## Отправка заявок

Форма пока никуда не отправляет. В `index.html`, в начале скрипта:

```js
var FORM_ENDPOINT = '';
```

Подставьте URL обработчика (CRM, Битрикс24, почтовый скрипт) — заявка уйдёт POST-запросом с JSON
`{name, phone, goal, day}`. Пока константа пуста, форма показывает подтверждение пациентке
и пишет предупреждение в консоль, а не делает вид, что письмо отправлено.

## Как устроена конверсия в короткой версии

- Плашка выбора дня в первом экране: JS рисует 7 ближайших дат от сегодняшней, выходные
  подсвечены золотом с подписью «работаем в обычном режиме»
- Выбранный день синхронизируется между первым экраном и формой, текст кнопки меняется
  на «Записаться на 8 авг»
- Кнопка «Получить второе мнение» заранее подставляет цель обращения в форму
- На мобильных — липкая панель «Позвонить / Записаться»

## Редактирование

Правки — прямо в веб-редакторе GitHub (`.` на странице репозитория или кнопка ✏️ в файле).
Стили и скрипты лежат внутри `index.html`, сборка не нужна: сохранили — через минуту
изменения на странице.
